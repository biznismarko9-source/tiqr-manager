# History

Every report, lab log and dated overview this project has had, moved here
from the top of the repository in 2.113.0 so the top holds only what is
needed to build and release the app. Nothing was deleted and no file was
renamed: a code comment that says "see REDESIGN-2.0.38-REPORT.md" means the
file of that name in this folder.

- `REDESIGN-<version>-REPORT.md` - one per release, written for marko, in
  Slovak: what changed, why, and what was checked.
- `*-REPORT.md` - reports on one feature (Price Checker, Finance, sync...).
- `*-LAB-LOG.md` - the design labs, screen by screen.
- `REDESIGN-OVERVIEW.md`, `VALIDACIA-2.76.0.md`, `tiqr-roadmap.html` -
  dated snapshots, kept as they were.
- `PROTECTED-AREAS-NOTES.md` - a pointer: the notes live in
  `PROJECT_STATE/PROTECTED_AREAS.md`.

The living documents are elsewhere: `PROJECT_STATE/` (current state, known
bugs, protected areas), `CHANGELOG.md`, `RELEASE.md` and `GMAIL-SETUP.md`.
